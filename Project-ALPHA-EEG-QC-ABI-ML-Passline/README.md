# Project Alpha EEG QC ABI ML Passline Submission

This is a minimal passing-line submission for:

`Project Alpha: Adaptive EEG QC Python ABI Integration`

Choose this project only if you are submitting Project Alpha. You do not need
to complete Project Beta.

## Contents

- `abi_runtime/eeg_qc_abi.py`: bundled Python-only ABI runner for no-Rust verification.
- `scripts/benchmark_complex.py`: one-command verification + complex benchmark package.
- `student_ml_plugin/plugin.py`: required ABI hooks implemented with a frozen ML model.
- `student_ml_plugin/params.json`: inference-time model parameters.
- `student_ml_plugin/model_manifest.json`: model provenance and status/reason labels.
- `student_ml_plugin/feature_manifest.json`: feature names and model feature order.
- `tests/test_plugin.py`: unit tests and one ABI integration test.
- `sample_abi/`: tiny ABI-compatible input files.
- `sample_output/plugin_output_v1.csv`: sample output generated by the ML plugin.
- `ABI_TUTORIAL.md`: step-by-step ABI usage and testing guide.
- `ABI_TEMPLATE.md`: hook signatures and ABI alignment checklist.
- `REPORT.md`: short report draft with the required section structure.

## Shared ABI

This ML version uses the same ABI as the non-ML version:

- same `windows_v1.csv`, `eeg_samples_v1.csv`, and `eog_samples_v1.csv` input shape
- same `qc_decision_v1(window, params)` hook
- same `feature_extractor_v1(window, params)` hook
- same output columns in `plugin_output_v1.csv`

Only the plugin implementation is different.

## No-Rust Student Verification

Students do not need Rust or cargo to verify this passline submission. From
this folder, run:

```bash
python3 scripts/benchmark_complex.py
```

The script uses only the Python standard library. It runs:

- unit tests
- sample ABI regression check on `sample_abi/` (including writing
  `sample_output/plugin_output_v1.csv`)
- direct benchmark cases
- ABI integration benchmark cases

It prints per-window ML decisions from `qc_decision_v1`
(KEEP/WARN/REJECT/ABSTAIN) and reason codes, with pass/fail summary.

Passing this passline benchmark means the code reaches the 60% baseline for the code component: it loads through the ABI, returns valid output, and performs initial EEG data-quality identification on the supplied examples. To earn higher benchmark credit, run this project's separate BCI IV 2a benchmark and report sensitivity, specificity, precision, F1, and balanced accuracy, plus failure analysis.

```bash
python3 scripts/run_bciiv2a_plugin_benchmark.py --max-trials 12
```

Remove `--max-trials 12` to run the full BCI IV 2a benchmark.

## Run the Sample ABI Directly

From this folder:

```bash
python3 abi_runtime/eeg_qc_abi.py \
  --windows sample_abi/windows_v1.csv \
  --eeg-samples sample_abi/eeg_samples_v1.csv \
  --eog-samples sample_abi/eog_samples_v1.csv \
  --plugin student_ml_plugin/plugin.py \
  --out sample_output/plugin_output_v1.csv
```

## ML Model Summary

The plugin performs fixed-weight ML inference:

- `_summary` extracts numeric signal features from each ABI window.
- `_model_features` transforms those features into model inputs.
- `MODEL_WEIGHTS` scores `KEEP`, `WARN`, and `REJECT`.
- `REASON_WEIGHTS` predicts reason labels such as `AMP_RANGE` and `FLATLINE`.

The model is embedded in `student_ml_plugin/plugin.py`, so no `sklearn`,
NumPy, network service, or separate model file is required. `ABSTAIN` is used
for empty windows where there is no usable signal for model inference.
